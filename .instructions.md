# Activate Now Flow - Project Structure & AI Development Guide

## Project Overview

**Activate Now Flow** is a full-stack web application built with Angular (frontend) and Spring Boot (backend) for educational fee payment activation with student verification.

### Tech Stack

- **Frontend**: Angular 19 (standalone components, routing, reactive forms)
- **Backend**: Spring Boot (Java)
- **Database**: MySQL
- **Build Tools**: Node.js, Maven, npm

## Key Conventions

### Frontend (Angular)

- **Standalone Components**: All components use standalone API
- **Styling**: SCSS with BEM naming convention
- **Forms**: Reactive Forms with custom validators
- **HTTP**: HttpClient with services for API calls
- **Routing**: Standalone routing configuration

### Backend (Spring Boot)

- **API Endpoints**: RESTful conventions
- **Database**: MySQL with JPA/Hibernate ORM
- **Packages**: Feature-based structure (controller, service, entity, dto, repository)

### Version Control

- **Branching**: feature/_, bugfix/_, hotfix/\* branches
- **.gitignore**: Configured to exclude sensitive data (application.properties, node_modules, target/)

## Building & Running

### Frontend

```bash
cd frontend
npm install                  # Install dependencies
npm run start               # Development server (http://localhost:4200)
npm run build               # Production build
npm run test                # Run unit tests
```

### Backend

```bash
cd backend
./mvnw clean install        # Build and run tests
./mvnw spring-boot:run      # Start application (http://localhost:8080)
```

### Database Setup

- Ensure MySQL is running on localhost:3306
- Create database: `dashboard_db`
- Update `application.properties` with credentials (keep in .gitignore)

## API Endpoints

### User

- `GET /user1` - Fetch user details (dashboard data)
- `POST /user` - Submit activation form (name, email, phone, pan)

## Form Validation Rules

### Phone Number

- 10 digits: `1234567890`
- International: `+919876543210`
- Regex: `^(?:\d{10}|\+91\d{10})$`

### Email

- Standard email format validation

### PAN (Permanent Account Number)

- Format: `ABCDE1234F` (5 letters + 4 digits + 1 letter)
- Regex: `^[A-Z]{5}[0-9]{4}[A-Z]$`

## UI Components

### Activation Modal

- **Selector**: `app-activation-modal`
- **Input**: None (uses service)
- **Output**: `closeModal` event emitter
- **Features**:
  - Real-time form validation
  - Green checkmarks for valid phone/email
  - Error messages for invalid inputs
  - Loading state during submission
  - Auto-closes on successful submission

### Dashboard

- **Selector**: `app-dashboard`
- **Features**:
  - Displays user details from API
  - Shows fee information
  - "Activate Now" button (disables after activation)
  - Integrates activation modal
  - Loading and error states

## AI Development Best Practices

### For GitHub Copilot

1. **Context**: Provide clear comments before code to guide suggestions
2. **Patterns**: Reference existing code patterns in the project
3. **Review**: Always review Copilot-generated code before committing
4. **Testing**: Run `npm run build` to catch TypeScript errors early
5. **Refinement**: Use multiple attempts if the first suggestion isn't perfect

### Copilot Keyboard Shortcuts

- `Ctrl+Enter` (Windows) / `Cmd+Enter` (Mac): Open Copilot suggestions
- `Alt+[` / `Alt+]`: Cycle through multiple suggestions
- `Escape`: Dismiss Copilot suggestions
- `Tab`: Accept suggestion

### When Copilot Works Best

- Scaffolding new components following project patterns
- Writing similar code to what exists in the project
- Implementing standard Angular/TypeScript patterns
- Generating unit test templates
- Writing documentation

### When to Use Manual Coding

- Complex business logic that's project-specific
- Critical security-related code
- Custom validation rules
- When Copilot suggestions don't match project patterns

### Improving Copilot Results


### Common Tasks

- **Add new route**: Update `app.routes.ts` and create component
- **Add API call**: Create service method in `src/app/services/`
- **Add validation**: Create validator function in `src/app/validators/`
- **Add component**: Generate with Angular CLI or follow naming convention
- **Style changes**: Use SCSS nesting and variables for consistency
